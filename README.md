# Nihongo Hub v2 🇯🇵

Website belajar bahasa Jepang statis untuk GitHub Pages.

## Fitur
- JLPT N5 / N4 / N3
- Pencarian kanji berdasarkan karakter, bacaan, dan arti
- Filter level kanji
- Pencarian kosakata
- Filter level kosakata
- Ringkasan bunpou
- Quiz pilihan ganda + skor
- Responsive untuk HP

## Upload
Upload `index.html`, `style.css`, dan `script.js` ke repository GitHub.
Lalu **Settings → Pages → Deploy from a branch → main → /(root)**.

Semua data dapat diedit di `script.js`.
